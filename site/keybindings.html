Key bindings

Three keymaps and the application shortcuts, 414 bindings in all. mod is cmd on macOS and ctrl on Linux and Windows. In the app, Settings › Keymap lists the same keys with their actions.

Registers

"{name} before a command. a-z set, A-Z append, 0 last yank, 1-9 numbered deletes (shifted like Vim: multi-line deletes and small deletes with % ( ) ` / ? n N { }), - small deletes, _ black hole, " unnamed, + and * the system clipboard (written on yank; p reads the clipboard the host last reported), / last search, . last inserted text, : last command line. :registers / :display list them in the status line.

Search

/ and ? open the prompt (enter accepts, esc cancels, a live preview moves the view). Patterns are Vim regex (\v \m \M \V, \< \>, \{n,m}, \( \), \|, \+ \? \=, classes \s \d \w \a \l \u \x, [], \c \C) translated to the regex crate; unsupported constructs are reported as errors, never silently reinterpreted. ignorecase and smartcase are on, wrapscan is on, hlsearch is on (:noh hides the highlights until the next search). Offsets (/pat/e, /pat/+1) work. n / N keep the direction; * # search the word under the cursor.
